# Pipeline xử lý audio

1. **Lấy âm thanh**: loopback hệ thống (Windows: WASAPI loopback qua crate `wasapi` — **không phải `cpal`**, xem [[PBI-6-capture-loopback-wasapi]]; **Linux: PulseAudio/PipeWire monitor source `@DEFAULT_MONITOR@` qua `libpulse-binding`/`libpulse-simple-binding`, xem [[PBI-18-loopback-linux]]**; macOS roadmap: BlackHole/ScreenCaptureKit) + mic (qua `cpal`).
2. **Resample**: `rubato` chuẩn hoá về 16kHz mono cho STT.
3. **VAD**: Silero VAD v5 qua crate `voice_activity_detector` (wrapper `ort`/ONNX Runtime, model nhúng sẵn) — gán nhãn speech/silence theo frame 512 sample @16kHz, xem [[PBI-9-vad-silero]]. Cắt đoạn (segment) theo khoảng lặng (state machine silence-hangover, không thêm dependency), xem [[PBI-10-cat-segment-khoang-lang]]. Streaming segmenter `VadPipeline` nối VAD + cắt segment vào luồng `start_capture` thật, phát event Tauri `vad-segment` ra UI mỗi khi 1 đoạn đóng — xem [[PBI-11-vad-segment-event]]. **M2 hoàn tất.**
4. **STT streaming**: local (`whisper-rs`/whisper.cpp) hoặc cloud (HTTP/WebSocket qua `reqwest`, `tokio-tungstenite`: Azure Speech Translation, Deepgram + LLM). **Cập nhật PBI 12**: đã cài đặt thật `WhisperSpeechToText` (local, whisper.cpp), xác nhận bằng model + giọng nói thật — xem [[PBI-12-stt-local-whisper]]. **Cập nhật PBI 13**: `TranscriptPipeline` nối `VadPipeline` (segment VAD, PBI 11) → `WhisperSpeechToText` (PBI 12) thành luồng end-to-end trên file audio mẫu, giữ đúng thứ tự thời gian — xem [[PBI-13-ghep-stt-vao-luong]]. **Cập nhật PBI 14**: `TranscriptPipeline` nối thật vào `start_capture`, phát event Tauri `transcript-partial`/`transcript-final` ra UI mỗi khi 1 segment có kết quả STT (hiện tại chỉ `transcript-final` vì whisper.cpp chưa hỗ trợ partial thật) — xem [[PBI-14-transcript-partial-final-event]]. **Cập nhật PBI 15**: xử lý lỗi runtime model (nạp/infer), phát event Tauri `model-error`, lỗi 1 segment không dừng pipeline — xem [[PBI-15-xu-ly-loi-runtime-model-stt]]. **M3 hoàn tất 4/4.**
5. **Dịch**: từng câu/cụm, kèm vài câu trước làm ngữ cảnh. **Cập nhật PBI 16**: `SidecarTranslator` cài đặt thật đầu tiên của trait `Translator`, chạy model qua **sidecar executable riêng** (crate Cargo độc lập `app/translate-sidecar/`, gọi qua `std::process::Command`) chứ không in-process — đổi hướng do xung đột CRT native giữa binding dịch (`ct2rs`) và `ort`/VAD, xem [[Rui-ro-ky-thuat]], [[PBI-16-dich-local-sidecar]]. Dịch đúng câu cố định (SC-001) **đã xác nhận bằng sidecar + model Marian-MT (opus-mt-en-vi, Apache-2.0) thật**. **Cập nhật PBI 17**: `translate()` nay ghép thật tối đa 2 câu ngữ cảnh + câu hiện tại thành 1 input gửi sidecar, tách bản dịch câu hiện tại bằng heuristic dấu kết câu (fallback dịch lại không ngữ cảnh khi tách thất bại) — xem [[PBI-17-dich-co-ngu-canh]]. **Cập nhật PBI 19**: bước 4→5 nay nối thật — `lib.rs::start_capture` tự động đưa mỗi câu `transcript-final` qua `translate_final_chunk` (hàm thuần mới, dùng `RecentTranscriptContext` làm ngữ cảnh), phát event Tauri `subtitle-ready` (câu gốc + câu dịch); lỗi dịch 1 câu báo qua `model-error` kiểu `translate`, không dừng phiên — xem [[PBI-19-noi-stt-dich-subtitle-ready]]. **M4: hoàn tất 3/3.**
6. **Hiển thị**: cửa sổ phụ đề nổi luôn-on-top; lưu transcript (SQLite) sau họp. **Chưa làm** — thuộc M5/M7, PBI 19 chỉ đảm bảo Core phát đúng event `subtitle-ready`, chưa có UI tiêu thụ.

Toàn bộ chạy trên `tokio` async runtime bên Core Rust.

## Trait trừu tượng hoá
`AudioSource`, `SpeechToText`, `Translator`, `SubtitleSink` — cloud/local là hai implementation khác nhau của cùng trait, xem [[Kien-truc-core-ui]].

## Trạng thái hiện tại
M1 (lấy âm thanh) đã hoàn tất **cho cả Windows và Linux**: capture mic qua `cpal` (PBI 5), capture loopback qua `wasapi` trên Windows (PBI 6) hoặc PulseAudio/PipeWire trên Linux (PBI 18 — cũng gate `wasapi` theo `cfg(windows)` để Linux build/test được), trộn 2 nguồn qua `MixedAudioSource` (PBI 7), command Tauri `start_capture`/`stop_capture` (PBI 8). M2 (VAD) đã hoàn tất: gán nhãn speech/silence theo frame qua `voice_activity_detector`/Silero VAD v5 (PBI 9), cắt buffer thành segment theo khoảng lặng (PBI 10), nối cả hai vào luồng capture thật + phát event Tauri `vad-segment` ra UI qua `VadPipeline` (PBI 11). M3 (STT streaming) đã hoàn tất 4/4: cài đặt thật `WhisperSpeechToText` bằng whisper.cpp local (PBI 12); `TranscriptPipeline` ghép segment VAD → STT end-to-end (PBI 13); nối thật vào `start_capture`, phát event Tauri `transcript-partial`/`transcript-final` (PBI 14); xử lý lỗi runtime model, phát event `model-error` (PBI 15). **M4 (Dịch) đã hoàn tất 3/3**: `SidecarTranslator` cài đặt thật trait `Translator`, chạy qua sidecar process riêng (PBI 16) — SC-001 đã xác nhận bằng model thật; dùng được ngữ cảnh 1-2 câu trước (PBI 17, SC-001 riêng của PBI 17 chưa xác nhận bằng model thật — xem [[Rui-ro-ky-thuat]]); và đã nối STT final → Translator → event `subtitle-ready` thật trong `start_capture` (PBI 19) — 65/65 test pass. Còn lại: bước 6 (hiển thị, thuộc M5) chưa làm.
