# Quickstart: Kéo-thả cửa sổ phụ đề (PBI 23)

1. `cd app && bun run tauri dev`
2. Chờ cửa sổ phụ đề nổi (không viền) xuất hiện.
3. Nhấn giữ chuột trái lên vùng cửa sổ phụ đề, kéo sang vị trí khác trên màn hình, thả chuột → cửa sổ nằm đúng vị trí mới (SC-001).
4. Chờ có `subtitle-ready` mới (hoặc gọi lại pipeline) để dòng phụ đề cập nhật/cuộn → cửa sổ không bị dịch chuyển (SC-002).
5. Click (không kéo) lên cửa sổ → cửa sổ không di chuyển (FR-005).
